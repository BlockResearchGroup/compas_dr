# Constrained form finding with dynamic relaxation

COMPAS DR finds equilibrium shapes of networks of axial members. Use the
NumPy solver for fixed supports, and use the constrained variant when support
vertices can slide along geometry. A pure-Python solver also covers networks
with prescribed densities, forces and lengths.

Start with [installation](installation.md) and the [worked example](examples.md).
The [solver and load guide](tutorial.md) explains the input and result
conventions.
